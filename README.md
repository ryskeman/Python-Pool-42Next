A structured collection of **Python 3** modules (`py00` through `py05b`) completed as part of the **42 Madrid** curriculum. The repository covers core language fundamentals, data structures, object-oriented programming (OOP), exception handling, algorithmic problem-solving, package architecture, and dependency management.

---

## 📚 Curriculum Modules Overview

| Module | Directory | Core Concepts Covered | Exercises |
| :--- | :--- | :--- | :--- |
| **Module 00** | [`./py00`](./py00) | Python syntax, built-in data types, control flow, functions, and basic I/O. | `ex0` – `ex7` |
| **Module 01** | [`./py01`](./py01) | Data structures (`list`, `tuple`, `dict`, `set`), comprehensions, and string manipulation. | `ex0` – `ex6` |
| **Module 02** | [`./py02`](./py02) | Object-Oriented Programming (OOP), classes, inheritance, encapsulation, and magic methods. | `ex0` – `ex4` |
| **Module 03** | [`./py03`](./py03) | Error and exception handling, file I/O, modules, packages, and decorators. | `ex0` – `ex6` |
| **Module 04** | [`./py04`](./py04) | Advanced data processing, algorithmic optimization, and modular code design. | `ex0` – `ex3` |
| **Module 05b** | [`./py05b`](./py05b) | Virtual environments (`venv`), dependency management (`pip`/`Poetry`), `.env` secrets, package architecture (`__init__.py`), relative/absolute imports, and circular dependency resolution. | `ex0` – `ex4` |
